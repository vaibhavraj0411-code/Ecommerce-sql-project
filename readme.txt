PROJECT TITLE: E-Commerce Sales Analysis using SQL

------------------------------------------------------------

📌 PROJECT DESCRIPTION:

This project focuses on analyzing e-commerce order data using SQL to derive meaningful business insights.  
The analysis helps understand revenue trends, customer behavior, and city-wise performance.

------------------------------------------------------------

📊 OBJECTIVES:

- Calculate total revenue generated
- Analyze revenue distribution across cities
- Identify top customers based on spending
- Detect repeat customers
- Study daily revenue trends
- Analyze revenue change over time

------------------------------------------------------------

🛠 TOOLS USED:

- SQL (MySQL)
- DB Fiddle (for query execution)

------------------------------------------------------------

📈 KEY INSIGHTS:

- Delhi generates higher total revenue compared to Mumbai
- Customer 102 is the highest spending customer
- Some customers are repeat buyers, indicating retention
- Revenue shows fluctuations across different dates
- City-wise performance highlights regional demand patterns

------------------------------------------------------------

📁 FILES INCLUDED:

- queries.sql   → All SQL queries used for analysis
- dataset.txt   → Raw dataset used in the project
- README.txt    → Project documentation

------------------------------------------------------------

🚀 CONCLUSION:

This project demonstrates the use of SQL for data analysis, including aggregation, filtering, and trend analysis.  
It highlights how raw data can be transformed into actionable business insights.
